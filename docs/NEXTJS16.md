# Next.js 16.3.6 — what differs from older habits (read before writing app code)

- `proxy.ts` replaces `middleware.ts` (deprecated). Lives at `src/proxy.ts`. `export function proxy(req: NextRequest)`. Node runtime only.
- `params` / `searchParams` are **always Promises**: `const { slug } = await props.params`. Types are global: `PageProps<'/l/[slug]'>`, `LayoutProps<'/dashboard'>`, `RouteContext<'/api/x/[id]'>` (generated by `next dev`/`next typegen`; do not import).
- `cookies()`, `headers()`, `draftMode()` are async only. Setting cookies works only in Server Actions and Route Handlers.
- `fetch` is NOT cached by default. Route handlers are not cached. We do **not** enable `cacheComponents`; do not use `'use cache'`, `cacheLife`, `cacheTag`.
- Server Actions: `'use server'` file or inline. Check auth inside every action. `redirect()` throws — call revalidation first. `useActionState` returns `[state, formAction, pending]`.
- `next.config.ts`: `images.remotePatterns` (not `domains`), `serverExternalPackages` (top level), `allowedDevOrigins` (hostname only) required for subdomain testing.
- Route handler: `export async function POST(req: NextRequest, ctx: RouteContext<'/api/[id]'>) { const { id } = await ctx.params; const body = await req.json(); return NextResponse.json(...) }`.
- `generateMetadata({ params, searchParams })` — both Promises. Set `metadataBase` in root layout. `opengraph-image.tsx`: `params` and `id` are Promises.
- `next/font/google` in root layout; `next/image`: `priority` is deprecated → use `loading="eager"` + `fetchPriority="high"`; remote images need `remotePatterns` and width/height or `fill`.
- Turbopack is default; `next build` fails if a `webpack()` config exists. `next lint` removed — run `npx eslint`.
- `error.tsx` is a client component with `{ error, retry }`. Every parallel-route slot needs `default.tsx`.
- React 19.2: `use(promise)` inside Suspense; `useFormStatus` from `react-dom`.
